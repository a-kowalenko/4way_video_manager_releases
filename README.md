# 4Way Video Manager Releases

Öffentliche Installer und Updater-Manifeste (`latest.json`) für
[4way_video_manager](https://github.com/a-kowalenko/4way_video_manager).

Builds werden per CI aus dem privaten Source-Repo hierher veröffentlicht.
Nicht für Quellcode gedacht — nur Release-Assets.

## Repo anlegen

```bash
gh auth login
gh repo create a-kowalenko/4way_video_manager_releases --public --description "4Way Video Manager installers & updater manifests" --add-readme
```

Diesen Textinhalt als README in jenes Repo übernehmen (oder den Auto-README belassen).
